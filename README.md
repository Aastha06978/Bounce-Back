# Bounce Back: Night Run

A fast-paced endless runner built with plain HTML, CSS, and JavaScript (Canvas). You control a white ball bouncing down a midnight city street. Switch lanes, jump over cars, grab coins, and keep going as the speed rises.

**The twist:** you get two "bounce backs". Crash into traffic and you recover instead of losing right away. The third hit ends the run.

## Features
- 3-lane pseudo-3D night road
- Swipe or keyboard controls (← → ↑, A/D/W, Space)
- Coin collection, scoring, and a saved best score
- Pause, resume, restart, and exit menu
- Works on desktop and mobile, with no installs or dependencies

## How to play
Open `index.html` in any modern browser.
